# NALAYA-THIRAN-IBM-PROGRAM-IBM-PBEL
 real-time communication project for specially-abled individuals 
Introduction

Communication is an essential part of everyday life, but people with hearing and speech impairments often face difficulties communicating with people who are unfamiliar with sign language. This project, Real-Time Communication System Powered by AI for Specially Abled, aims to reduce this communication gap using Artificial Intelligence and Computer Vision.

The proposed system uses a camera to capture hand gestures and a Convolutional Neural Network (CNN) model to recognize American Sign Language (ASL) alphabet gestures. The recognized gesture is then converted into a corresponding English alphabet and displayed on the screen in real time.

The application is developed using Python, OpenCV, TensorFlow/Keras, and Flask. OpenCV captures the user's hand gestures through a webcam, while the trained deep learning model performs gesture classification. Flask provides a web-based interface through which users can access the real-time sign recognition system.

The current implementation recognizes ASL alphabets from A to Z. The system can be further enhanced by incorporating gesture recognition for the remaining alphabets, numbers, words, and complete sentences. The project demonstrates how AI-based computer vision can be applied to develop accessible communication solutions and support more inclusive interaction between sign-language users and the wider community.
